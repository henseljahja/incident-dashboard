# i18n

## Intent

**The UI chrome ships in English and Indonesian; the data never changes language.** Every label,
heading, button, message and ⓘ definition comes from `vue-i18n` (Composition mode,
`legacy: false`, `fallbackLocale: 'en'`). Everything that arrived from Redmine or the mart is
rendered exactly as delivered.

**Surfaces:** `FrontEnd/incident-dashboard/src/i18n/` (runtime + `locales/en.json`, `locales/id.json`),
`src/stores/locale.ts` (the one place the locale changes), `LanguageSwitch.vue`.

## Required Checks

- **No chrome literal in a template or script.** Visible copy, `aria-label`, `title`,
  placeholders and validation messages go through `t()`. A new key lands in `en.json` AND
  `id.json` in the same change.
- **Data values are never keys:** status names, tracker names, priority names, stage names,
  category/institusi values, `Unclassified`, `Unknown (<id>)`, `Unmapped`. The only enums mapped
  client-side are `SLA_BUCKET` (`charts.bucket.*`), `CLOSE_BASIS` (`definitions.closeBasis.*`),
  facet tokens (`filters.chip.*`) and account status (`admin.status.*`) — each with a raw-value
  fallback for a value the map does not know.
- **Parity is a test, not a review item:** `src/i18n/__tests__/parity.spec.ts` fails when either
  locale file has a key the other lacks.
- **Numbers and dates use `Intl` with the active locale** (`utils/number.ts`, `utils/date.ts`).
  No `toFixed`, no `toLocaleString()` without a locale. Filter bounds stay `YYYY-MM-DD` —
  they are query values, not display text.
- **Message syntax:** avoid `@`, `|`, `{`, `}` in copy — they are vue-i18n syntax (linked
  messages, plurals, placeholders).
- **Locale state:** only `useLocaleStore().setLocale()` writes `localStorage['incident.locale']`
  (inside try/catch), `i18n.global.locale`, `<html lang>` and the PrimeVue locale. Anything
  stored other than `en`/`id` boots as `en`.
- **Tests are pinned to English:** the vitest setup resets the locale to `en` before every test,
  so existing text assertions keep proving the English copy; Indonesian rendering is asserted
  explicitly. Playwright seeds `incident.locale=en` through `e2e/fixtures/test.ts` (specs import `test`/`expect` from there, not from `@playwright/test`), and
  `e2e/locale.spec.ts` is the one Indonesian smoke test.
